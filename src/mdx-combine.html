Генератор постов для Astro/Retypeset: frontmatter по ТЗ + конвертация HTML в Markdown. Защита от пустых полей, память повторяющихся полей.

description намеренно отсутствует — его формирует тема из toc.
published пишется как YYYY-MM-DD (без времени и Z — иначе сборка падает).
abbrlink оставите пустым — ключ abbrlink: в файл не попадёт, имя файла соберётся из slug.
Заголовок обязателен
Только строчные a-z, цифры и дефис. Пусто — ключ abbrlink: не выводится.
Нужен валидный slug: строчные a-z, 0-9, дефис; без заглавных и подчёркиваний
Контент обязателен
abbrlink + slug через дефис; при пустом abbrlink — только slug; дубль «slug-slug» не собирается.

Preview — побайтово то, что уйдёт в файл
