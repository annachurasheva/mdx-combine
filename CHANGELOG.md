# Changelog

## [1.1.2] - 2026-09-29
- published: ручная дата источника — убрана автоподстановка текущей даты; добавлено поле `<input type="date" id="published">` в карточке метаданных с label «Дата публикации (из источника) *» и подписью «Дата оригинального поста на архивном источнике — вручную». По умолчанию пусто. Валидация `^\d{4}-\d{2}-\d{2}$`: пока пусто или невалидно — «Создать .md» неактивна, красная рамка и текст ошибки под полем. В PERSIST не добавлялось.
- updated: автоматическая текущая дата — при генерации `const now = new Date().toISOString().split('T')[0]`, в файл уходит строка `updated: YYYY-MM-DD`; строка `"updated: ''"` из шаблона удалена.
- Состав и порядок frontmatter не менялись: title, abbrlink, published, updated, tags, draft, pin, toc, lang, authorIds. Preview показывает обе даты ровно так, как они уйдут в файл.
- Метка сборки: build 1.1.2 (`<!-- build: 1.1.2 -->` в `<head>` и бейдж `#buildStamp`).

## [1.1.1] - 2026-09-29
- Имя файла всегда = slug заголовка (`<slug>.md`); ветка `abbrRaw + '-' + slug` и защита от дубля «slug-slug» удалены; abbrlink в имени файла не участвует.
- abbrlink добавлен в PERSIST (память повторяющихся полей); «Сбросить память» очищает поле abbrlink.
- Отменено автозаполнение abbrlink из title: обработчик транслита и dirty-флаг удалены, поле — только ручной ввод. Label: «Abbrlink (только ручной ввод)».
- Condition кнопок уточнён: «Создать .md» активна при непустых title и контенте и (пустом или валидном `/^[a-z0-9-]+$/`) abbrlink.
- Paste-обработчик контента: HTML из буфера вставляется в позицию курсора с поднятием события `input`.
- Конвертер: `<img>` → `![alt](src)` (alt только внутри скобок, без подстановки «Изображение»); ссылка вокруг картинки → `[![alt](src)](href)`; вырезается `im_/`; относительные src → `/assets/`.
- Самопроверка метки сборки: IIFE сверяет бейдж `#buildStamp` с комментарием `<!-- build: 1.1.1 -->` в `<head>`, при расхождении красит бейдж и пишет `console.warn`.

- Добавлены .vscode, doctor.html, VERSIONS.json, скрипты check/promote/archive.
