MDX-Комбайн: Авто-транслит + Защита

Версия, которая не даст создать файл с ошибками. Автоматически генерирует abbrlink из заголовка.

Только a-z, 0-9, дефис. Без заглавных!
Как это работает теперь:
1. Введи заголовок. Abbrlink заполнится автоматически (транслит + slug). Можешь переписать вручную, но формат должен быть строгим.
2. Кнопка "Создать" станет активной только когда все обязательные поля заполнены.
3. Дата будет в формате YYYY-MM-DD (без времени), чтобы не ломать сборку.
